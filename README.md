# Bigfin

Система управленческого учёта и финансовой отчётности для предпринимателей.

Bigfin помогает собственникам бизнеса видеть реальную картину денег и принимать
обоснованные решения — без бухгалтерского образования. Российский аналог
Fintablo и PlanFact с возможностью развёртывания на собственных серверах.

## Возможности

- Управленческий учёт (метод начисления и кассовый)
- Финансовая отчётность: P&L, ДДС, баланс
- Учёт по проектам, направлениям, юр. лицам
- Многовалютность с поддержкой RUB
- Импорт банковских выписок
- API для интеграций

## Установка

### Docker (рекомендуется)

```bash
docker compose up -d
```

После старта откройте http://localhost:80

### Локальная разработка

Требования: Node.js 18.16.1, pnpm, PostgreSQL, Redis.

```bash
pnpm install
pnpm build
pnpm dev
```

Подробнее в [CONTRIBUTING.md](CONTRIBUTING.md).

## Стек

- **Бэкенд:** Node.js, TypeScript, NestJS, PostgreSQL, Redis, Knex
- **Фронтенд:** React, TypeScript, Vite
- **Монорепо:** lerna + pnpm workspaces
