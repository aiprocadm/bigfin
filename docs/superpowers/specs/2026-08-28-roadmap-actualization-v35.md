## 1. Что дала разведка

Разведка проверяла то, чем человек пользуется, когда данные нужны за
пределами продукта: сторону закупок и кнопки «Печать» и «Экспорт».

Здоровым оказалось многое: счета поставщиков считают и говорят по-русски
(«Просрочен на 1 дн.», «Частично оплачен, осталось 10 000,00 ₽»);
выгрузка отчёта в XLSX отдаёт настоящий файл на 23 КБ, в CSV — русский
текст, PDF — настоящий PDF на 40 КБ. Ничего не сломано.

Беда в другом: **этими файлами нельзя пользоваться по назначению.**

### Линия 1 (главная). В выгрузке отчёта нет ни одного числа

Выгружаем баланс в XLSX и смотрим, что внутри:

```
A1: 'Название статьи'   B2: '2 975 000,00 ₽'
                        B6: '120 000,00'
```

Замер по файлу: **102 ячейки, из них числовых — 0**. Все суммы записаны
строками: неразрывные пробелы между разрядами, запятая как разделитель,
знак рубля внутри значения.

Для Excel это текст. Столбец нельзя сложить, нельзя отсортировать по
величине, нельзя построить график. Бухгалтер выгружает отчёт ровно
затем, чтобы посчитать — и первым делом чистит файл руками.

Для сравнения — выгрузка списка счетов из другого места продукта:
**408 ячеек, из них 40 числовых**. Там числа записаны числами.

Причина одна и общая. Экспорт отчётов собирается из готовой таблицы, а в
её ячейке лежит только подпись:

```ts
export interface ITableCell {
  value: string;   // «2 975 000,00 ₽»
  key: string;
}
```

Общее место одно — `TableSheet`, и им пользуются **17 отчётов**: баланс,
прибыли и убытки, движение денег, ОСВ, главная книга, журнал, обе
задолженности по срокам, продажи и закупки по позициям, склад, налоги и
другие. Одна правка чинит все.

### Линия 2. Прямой запрос выгрузки отвечает пустотой или падает

Контроллер выгрузки читает заголовок запроса, не проверив его:

```ts
if (acceptHeader.includes(AcceptType.ApplicationCsv)) { … }
```

Что получается:

| Как просят | Ответ |
|---|---|
| `accept: application/xlsx` (так ходит витрина) | файл, 33 КБ |
| `accept: */*` (обычный браузер, ссылка) | 200 и **пустое тело** |
| заголовка нет вовсе | **500**, «Cannot read properties of undefined» |

Соседний контроллер баланса от этого защищён — `const accept =
acceptHeader || ''`. Здесь защиты нет.

## 2. Фаза «Выгрузка, которую Excel не считает» — срезы

1. **Н1 — суммы выгружаются числами.** Общее место разбирает подпись
   обратно в число, когда это число, и пишет его числом с форматом
   отображения; текст (названия, коды, даты) остаётся текстом. Сторож:
   в выгрузке отчёта есть числовые ячейки.
2. **Н2 — выгрузка отвечает осмысленно на любой заголовок.** Нет
   заголовка или `*/*` — отдаём формат по умолчанию, а не пустоту и не
   ошибку.

Порядок: Н1 → Н2.
Каждый срез: красный тест → правка → полные прогоны → живая проба
(скачать файл и заглянуть внутрь) → PR с числами.
