## 2. Словарь статусов

| Статус | Что означает |
|---|---|
| `не начат` | Кода нет, ветки нет |
| `в работе` | Есть ветка, есть коммиты, PR ещё не открыт |
| `на ревью` | PR открыт, ждёт владельца или CI |
| `влит` | PR в `develop` |
| `принят` | Владелец проверил вживую и подтвердил приёмку из ТЗ |
| `заблокирован` | Нужно решение владельца или внешнее условие |

Этап считается **закрытым** только в статусе `принят`. `влит` ≠ `принят`.

## 5. Режим «Стабилизация»

Включается, когда по ТЗ работы нет: все этапы `принят`, либо очередь упёрлась
в ожидание владельца (`заблокирован` / «ждём от владельца»), либо владелец
явно попросил стабилизацию.

Источники работы — **строго в этом порядке**, брать первый непустой:

| # | Источник | Как проверить |
|---|---|---|
| 1 | Красный CI на открытых PR | `gh pr list --state open` → `gh pr checks <N>` |
| 2 | Падающие тесты на `develop` | `pnpm --filter @bigfin/server test`, `pnpm --filter @bigfin/webapp test` |
| 3 | Ошибки типов | `pnpm typecheck` |
| 4 | Непарные переводы | `node packages/webapp/scripts/lang-check.js` |
| 5 | Долг по `@ts-nocheck` | линия карт v84–v87, ~148 файлов. **Внутри работ по ТЗ эти файлы не трогать** — но в режиме стабилизации это законная работа |
| 6 | Непокрытые сторожевые спеки | `navigationReachability`, `routePathsAreReal`, `sidebarHonoursMenuGuards`, `emptyStateTexts`, `moduleDisabledSpeaks`, `tableScrollOnPhone` — расширять, не отключать |
| 7 | Дыры в e2e | `e2e/`, Playwright: основной суточный сценарий из E3 ТЗ |
| 8 | Известные грабли | раздел «Known gotchas» в `CLAUDE.md` |

Результат стабилизации оформляется так же: одна тема = один PR, зелёный прогон,
запись в «Журнал» ниже.
