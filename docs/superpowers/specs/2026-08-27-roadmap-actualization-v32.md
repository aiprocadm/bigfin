### Линия 1 (главная). Дату рисует браузер, а не продукт

В форме «Добавить ОС» поле «Дата ввода в эксплуатацию» показывает

```
08/27/2026
```

Это американский формат: месяц, день, год. Так его рисует **браузер**,
потому что поле — системное `<input type="date">`, а тестовый браузер
английский. У человека с русским браузером будет иначе; продукт на это
не влияет никак.

Замер: **17 экранов, 24 поля**. Это долг, записанный ещё картой v26:
тогда починили период «Анализа НДС», а остальные перечислили явным
списком в стороже.

Важно: **дата сохраняется правильно** — у созданного объекта в базе
`COMMISSIONED_AT = 2026-08-27`. Изъян только в показе, но именно показ
человек и видит.

И вот что делает эту линию простой: **у продукта уже есть своё поле
даты**. `components/ui/date-picker` — календарь в стиле нового
интерфейса, и им уже пользуются девять экранов (счета покупателям,
сметы, чеки, приход и расход денег, отчёты, счета поставщиков). Эти
семнадцать просто до него не дошли.

### Линия 2. Своё поле даты тоже печатает зашитым форматом

Внутри `date-picker` дата печатается так:

```ts
{value ? moment(value).format('DD.MM.YYYY') : placeholder}
```

Формат вписан в код. У организации, где выбран другой формат даты
(настройка есть в «Общих»), поле покажет `27.08.2026`, а списки рядом —
`2026-08-27`. Это ровно тот изъян, который карта v25 чинила у легаси-полей
(утилита `formatOrganizationDate` для этого и появилась) — до нового
компонента она не дошла.

## 3. Фаза «Дату рисует браузер» — срезы

1. **Ж1 — своё поле даты печатает по формату организации.** `DatePicker`
   переходит с зашитого `DD.MM.YYYY` на `formatOrganizationDate`. Рядом
   появляется строковая обёртка `DateField`: экраны хранят дату строкой
   `ГГГГ-ММ-ДД`, а компонент работает с `Date` — обёртка избавляет от
   перевода в каждом из семнадцати мест.
2. **Ж2 — семнадцать экранов переходят на поле продукта.** Долг в стороже
   `systemDateInputGuard` обнуляется: список исключений становится
   пустым.

Порядок: Ж1 → Ж2.
Каждый срез: красный тест → правка → полные прогоны → живая проба на
собранной витрине → PR с числами.
