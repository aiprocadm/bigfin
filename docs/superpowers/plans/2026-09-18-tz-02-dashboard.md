## Что сделано в шаге 2.2 (сервер)

Заведена ручка **`GET /dashboard/overview?from=&to=`** — всё для главной одним
ответом (п. 2.3 ТЗ: «пять отдельных запросов на главной недопустимы»):

| Блок ответа | Что внутри |
|---|---|
| `tiles` | деньги на счетах, доходы, расходы, прибыль — каждая с изменением к прошлому периоду; у прибыли ещё рентабельность |
| `months` | двенадцать месяцев: доходы, расходы, прибыль — ряды графика |
| `accounts` | остатки по денежным счетам |
| `topExpenses` | пять крупнейших статей расходов с долей в расходах периода |

**Главное правило соблюдено: второго способа считать те же суммы нет.**
Доходы, расходы и прибыль берутся из узлов отчёта о прибылях и убытках —
тех же, что видит человек в разделе «Отчёты». Остатки — из `GetMoneySummary`.
Иначе главная и отчёт разойдутся, и верить будет нечему.

Отдельные решения, записанные в коде:

- **Период по умолчанию — текущий месяц** (п. 2.2 ТЗ).
- **Сравнение — с предыдущим периодом такой же длины**, а не «с прошлым
  месяцем вообще»: март сравнивается с 31 днём до него.
- **Ноль в знаменателе — это «сравнивать не с чем», а не «рост на 100%»**:
  изменение отдаётся пустым.
- График берётся **одним запросом** с разбивкой по месяцам, а не двенадцатью.

**Тест** `GetDashboardOverview.spec.ts` — 7 проверок, среди них требование ТЗ
о сверке с отчётом. Проверен мутацией: «округление» доходов на входе роняет
две проверки.

**Прогон:** сервер 2321 тест / 348 наборов, `tsc` сервера чист, словари
4282 / 4282.

**Как проверить:** `GET /dashboard/overview` без параметров отдаёт текущий
месяц; суммы `tiles.income`/`tiles.expenses` совпадают с отчётом о прибылях и
убытках за тот же период.
**Как откатить:** `git revert` коммита шага 2.2.

## Задел на шаг 2.3

Блок «Требует внимания» из п. 2.2 ТЗ пока не в ответе: его строки берутся из
разных мест (неразнесённые операции, кассовый разрыв из платёжного календаря,
просроченная дебиторка, заявки на оплату, превышение бюджета). Часть из них
уже готова (`GetMoneySummary`, счётчик ждущих разноски), часть требует своих
запросов — соберу вместе с витриной, чтобы не гадать о формате.
