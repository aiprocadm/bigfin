## 1. Что дала разведка

### Находка. Из шести разделов искать есть что в четырёх

Механическая правка «добавить поиск во все шесть» была бы неверной. Разбор
по одному (урок карт v46 и v47):

| Раздел | Что искать | Решение |
|---|---|---|
| Кредиты и займы | `name` — «Кредит Сбербанка на станок» | **добавлен** |
| Зарплата → сотрудники | `fullName` | **добавлен** |
| Бюджеты | `name` | **добавлен** |
| Платёжный календарь → плановые операции | `description` | **добавлен** |
| Дивиденды | только `note`, примечание к выплате | нет |
| Долги | текстовых полей нет вовсе | нет |

**Почему дивиденды — нет.** У выплаты есть дата, сумма, два счёта и
необязательное примечание. Искать по примечанию — значит искать по полю,
которое чаще всего пустое. Выплата дивидендов — редкое событие, список
короткий, и человек видит его целиком.

**Почему долги — нет.** Это не список записей, а **свод**, который
считается на лету из счетов и оплат по каждому контрагенту. Искать там
можно только имя контрагента — а контрагентов поиск и так находит, своим
видом записей. Второй вход в то же самое запутает, а не поможет.

## 2. Фаза «Последние разделы» — срезы

1. **Ш1 — кредиты ищутся по названию.**
2. **Ш2 — сотрудники ищутся по имени.**
3. **Ш3 — бюджеты ищутся по названию.**
4. **Ш4 — плановые операции ищутся по описанию.**

Каждый срез — обе стороны: список принимает запрос на сервере, витрина
знает вид записей, а найденное открывается на странице.

---

## 3. Что сделано

### Сервер

Четыре списка приняли запрос поиска и применили общий помощник карты v43.
Колонки поиска раздел объявляет у себя, в модели.

**Самое рискованное место — платёжный календарь.** У его списка уже четыре
фильтра: направление, счёт и две границы дат. Поиск добавляется к ним, а не
вместо них, и «или» из поиска не должно размыть ни один — иначе человек
увидел бы в календаре чужие месяцы. Отдельный тест держит это на живом SQL:
проверяются и направление, и обе границы.

### Витрина

Четыре вида записей: адрес запроса, разбор ответа, привязка к окну поиска и
объявление на маршруте. Разбор ответа — общий: все четыре списка отдают
массив, иногда завёрнутый в `data`.

### Найденное открывается

Продолжение среза Р5 карты v43. Способ выбран по устройству раздела, а не
по шаблону:

- **кредиты** и **бюджеты** — раскрывают карточку найденной записи;
- **сотрудники** — своей страницы не имеют, реестр показывает их списком:
  найденный **выделяется**, экран прокручивается к нему;
- **платёжный календарь** — не открывает операцию отдельным экраном вовсе,
  он показывает её среди соседних дней: найденная строка выделяется в своём
  дне.

У кредитов и бюджетов закрытие карточки убирает номер из адреса — иначе
карточка, открытая поиском, возвращалась бы сразу после закрытия.

### Чем закрыт задел карт v39 и v43

Поиск теперь знает **семь** разделов, добавленных позже классических:
сделки, заявки на оплату, основные средства (карта v43), кредиты,
сотрудники, бюджеты, плановые операции (эта карта). Два оставшихся —
дивиденды и долги — закрыты решением «искать нечего», с записью почему.
