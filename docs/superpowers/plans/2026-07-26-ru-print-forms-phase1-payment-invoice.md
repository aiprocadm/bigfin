## Фаза 4 — ТОРГ-12 и Счёт-фактура (закрывает ②c)

**ТОРГ-12** (`GET /ru-print-forms/sale-invoices/:id/torg12`, альбомная) — унифицированная
форма по постановлению Госкомстата № 132: отсылка к форме, коды (ОКУД `0330212`),
грузоотправитель/грузополучатель/поставщик/плательщик, основание, 15 граф с
трёхуровневой шапкой (группы + служебная строка номеров), «Итого» и «Всего по
накладной», число записей и сумма прописью, блоки подписей.

**Счёт-фактура** (`GET /ru-print-forms/sale-invoices/:id/invoice-factura`, альбомная) —
приложение № 1 к постановлению № 1137: строки (1)…(8) и 19 граф (1, 1а, 1б, 2, 2а,
3…9, 10, 10а, 11, 12, 12а, 13, 14), включая графы прослеживаемости; «Всего к оплате»
с «Х» в неприменимых ячейках; подписи руководителя и главбуха, а для ИП (ИНН из
12 цифр) — один блок с ОГРНИП.

**Общий код фазы 4:** `formatDateNumericRu` (дата цифрами — в унифицированных бланках),
`mapEntriesToRuVatLines` (единый построчный расчёт НДС; УПД переведён на него),
`buildOrganizationAddress` / `buildContactShippingAddress` / `buildOrgRequisitesLine` /
`buildContactRequisitesLine` / `formatInnKpp` / `isSoleProprietorInn` /
`hasGoodsEntries` / `stripHtmlToText`, константы `DASH` / `CROSS` / `NO_VAT`,
`buildAmountInWords` (не даёт упасть генерации на отрицательном итоге).
Контроллер: общий `respondWithForm` вместо пяти копий content negotiation.

**Сознательные упрощения фазы 4** (в формах ставится прочерк):

- единица измерения и код по ОКЕИ — у модели `Item` нет поля единицы измерения;
- ТОРГ-12: коды ОКПО/ОКДП, вид упаковки, число мест, масса брутто/нетто,
  транспортная накладная, вид операции, структурное подразделение, приложения;
- счёт-фактура: исправление, платёжно-расчётный документ, документ об отгрузке,
  код вида товара, акциз («без акциза»), страна происхождения, номер декларации,
  все графы прослеживаемости, идентификатор госконтракта;
- подписанты не подставляются — справочника подписантов в продукте нет.

**Требует сверки перед боевым применением:** дословные формулировки граф взяты из
вторичных источников; перед выдачей форм внешним пользователям сверить с текстом
постановлений на pravo.gov.ru. Формы напечатаны с «ё» — единообразно с остальными
формами продукта.
