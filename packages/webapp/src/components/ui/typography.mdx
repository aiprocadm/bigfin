# Типографика Bigfin

**Один шрифт — Inter Variable** с оптическими размерами: крупные заголовки
набираются плотнее, мелкий текст — разборчивее. Фирменный шрифт Apple в веб
встраивать нельзя (лицензия), Inter ближе всех по рисунку (R1 ТЗ-4).

**Все суммы — моноширинными цифрами** (`tabular-nums`, включено во всём
`.bigfin-ui`): столбцы выстраиваются по разрядам.

Размеры берутся **только из шкалы** — классами `text-hero` … `text-caption`.
Размер «на месте» (`text-[13px]`) — нарушение: за этим следит проверка
`noRawDesignValues.spec.ts`, а за полнотой этой страницы —
`typographyDocMatchesTheme.spec.ts`.

## Шкала (ТЗ-4 §5.2)

| Класс | Размер / строка / начертание | Трекинг | Где |
|---|---|---|---|
| `text-hero` | 44 / 48 / 600 | −0.025em | сумма-герой главной |
| `text-large-title` | 32 / 38 / 700 | −0.022em | заголовок страницы |
| `text-title-2` | 22 / 28 / 600 | −0.017em | заголовок раздела |
| `text-title-3` | 20 / 25 / 600 | −0.015em | заголовок карточки-блока |
| `text-headline` | 15 / 20 / 600 | −0.01em | заголовок группы, шапка при прокрутке |
| `text-body` | 14 / 20 / 400 (телефон 15 / 22) | −0.006em | основной текст |
| `text-callout` | 14 / 20 / 500 | 0 | суммы в таблицах |
| `text-subhead` | 13 / 18 / 400 | 0 | подписи, вторичный текст |
| `text-footnote` | 12 / 16 / 400 | 0 | пояснения, оси графиков |
| `text-caption` | 11 / 13 / 500 | +0.01em | метки на графиках, счётчики |

Прописные буквы для подписей не используются (`noShoutingLabels`).
