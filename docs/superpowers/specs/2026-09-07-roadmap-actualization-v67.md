# Bigfin — Дорожная карта v67 «Один довод лишний» — 2026-09-07

Карта v66 влита (#397). Задел: 38 мест «ожидался 1 довод, передано 2» в 30
надстройках над хранилищем — с записанной там причиной.

Поручение владельца: решения принимать самому.

---

## 1. Причина из карты v66 оказалась неверной

Карта v66 записала: виноваты несогласованные типы состояния в `reselect` —
у одного входа `RootState`, у другого `unknown`, и вывод схлопывает результат
до одного довода.

Проверить это дёшево: положить рядом пробный файл, который **проверяется**
(не под пометкой), и позвать оттуда оба отборщика.

```ts
export const a = (state: RootState, props: any) => two(state, props);  // тихо
export const b = (state: RootState, props: any) => one(state, props);  // ошибка
```

Отборщик, собранный из двух входов, спокойно принял два довода. Значит, дело
не в типах состояния.

**Настоящая причина проще.** Часть отборщиков собрана из **одного** входа, и
тот берёт только состояние:

```ts
createSelector((state: RootState) => state.manualJournals.selectedRows, (rows) => rows)
```

Такому отборщику свойства экрана не нужны и никуда не передаются — а зовут
его как `getSelectedRows(state, props)`. Во время работы `reselect` лишний
довод просто игнорирует; проверка типов — нет.

**Урок:** догадка о причине проверяется пробным файлом за две минуты. Карта
v66 записала догадку как вывод.

## 3. Что сделано

### Д1. Пункт меню

`MenuItem` — наш класс-компонент, скопированный когда-то из blueprint,
написан как `extends AbstractPureComponent2` без доводов типа. Из-за этого
тип экземпляра не считается элементом JSX. Проставлены `<any, any>`;
проверено тем же приёмом с пробным файлом.

### Д2. Лишний довод

Убран в 38 местах, 30 надстроек. Поведение не меняется: довод и раньше
никуда не доходил.

Одно из этих 38 мест — не отборщик: во вспомогательной
`nestedArrayToflatten` внутренняя `parseObject` берёт один довод, а `level`
читает из замыкания. Второй довод там был так же бесполезен; проверено
чтением кода, а не догадкой — после того, как я увидел этот файл в списке и
удивился.
