# Приёмка блока Б5 «Управленческая глубина» (ТЗ-3, раздел 31)

Этот документ — для владельца. По каждому пункту чек-листа раздела 31
`MASTER-3.md` написано, **где смотреть** в продукте, **что должно получиться**
и **чем уже проверено** до вас (автоматические проверки и живые проверки на
стенде `fin.ptsfera.online`, демо-организация `demo@bigfin.local`).

Отметки «✔ живьём» означают: сценарий прогнан на стенде после выкладки, числа
сверены с базой. Итог приёмки ставите вы: пройдите пункты руками и отметьте
в последней колонке.

Как читать колонку «Проверено»: «тесты» — автоматические проверки в коде;
«живьём N» — живая проверка этапа N (подробности в журнале `STATE.md`).

## Что требует решения владельца

1. Подключить ИИ-модель (Настройки → ИИ-аналитик), если нужен пересказ ответов
   AI CFO словами модели. Без модели AI CFO отвечает по расчёту.
2. Вопросы из журнала `STATE.md` (раздел «Указатель»): удалить неиспользуемый
   ключ перевода, объединить два списка «первых шагов», отдельный вид операции
   для корректировки остатка, старые хуки чата `useAiChatTools`/`useAskAiChat`.
