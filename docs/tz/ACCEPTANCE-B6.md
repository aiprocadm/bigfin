# Приёмка блока Б6 «Современный интерфейс» (ТЗ-4, раздел 11)

Этот документ — для владельца. По каждому пункту чек-листа раздела 11
`MASTER-4.md` написано, **где смотреть**, **что должно получиться** и **чем уже
проверено** до вас. Итог приёмки ставите вы: пройдите пункты руками и
отметьте в последней колонке.

Как читать колонку «Проверено»:
- «тесты» — автоматические проверки в коде (`pnpm --filter @bigfin/webapp test:run`);
- «axe» — проверка доступности `e2e/a11y.spec.ts` (26 экранов × светлая и тёмная);
- «снимок» — эталонный снимок экрана в `e2e/visual/snapshots/`;
- «живьём N» — живой проход этапа N на локальной копии витрины со стендовыми
  (демо) данными; подробности — в журнале `STATE.md`.

> Все проверки Б6 сделаны на локальной копии, а не на стенде
> `fin.ptsfera.online`: GitHub Actions на время работы были заблокированы по
> оплате, выкладки не было. Перед приёмкой на стенде нужна выкладка ветки.

### Как переснять

```bash
# витрина на :4000 и сервер на :3000 подняты; вход — из окружения
PLAYWRIGHT_EMAIL=… PLAYWRIGHT_PASSWORD=… npx playwright test visual/screens.spec.ts --update-snapshots
# либо ответ сервера на вход в демо-организацию:
PLAYWRIGHT_SIGNIN_FILE=signin.json npx playwright test visual/screens.spec.ts
```

Данные демо строятся от сегодняшней даты: через некоторое время суммы и
подписи дат разойдутся с эталоном — это ожидаемо, эталоны переснимаются и
просматриваются глазами перед коммитом.
