## Как продолжить работу

В сессии Claude Code достаточно написать:

```
продолжай по ТЗ
```

Сработает алгоритм из [CONTINUE.md](CONTINUE.md): `git fetch`, чтение
`STATE.md`, определение этапа в работе или следующего по очереди, продолжение
с той же точки. Очередей две — сначала блоки Б1–Б3 (`MASTER.md`), затем блок Б4
(`MASTER-2.md`). Если работы по ТЗ нет ни там, ни там — перейдёт к
стабилизации: CI, падающие тесты, типы, переводы, долг по `@ts-nocheck`,
сторожевые спеки, e2e.

Эквивалент — слэш-команда `/tz`. С уточнением: `/tz этап 6`,
`/tz стабилизация`, `/tz статус`.

## Отношение к картам

`docs/superpowers/specs/*-roadmap-actualization-vNN.md` — летопись: что было
сделано в такой-то день. Она накапливается и не отвечает на вопрос «что делать
сейчас». `STATE.md` — наоборот: один файл, перезаписывается, отвечает только на
этот вопрос. Одно другое не заменяет.
