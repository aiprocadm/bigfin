# Bigfin — Дорожная карта v30 «Деньги без рубля, часть вторая» — 2026-08-27

Карта v29 закрыта целиком (#351, #352): тип счёта переведён, счёт без
движений печатает ноль, в демо появились деньги. Владелец 27.08 передал
право принимать решения самостоятельно — прежние вопросы 39, 42 и 43
закрыты этой картой (см. раздел 3). GitHub Actions по-прежнему выключены,
проверки гоняются вручную и приводятся числами в PR.

---

## 1. Что дала разведка

Разведка шла по следу карты v29: демо получило деньги, и стало видно, как
продукт показывает их на экране «Расходы».

### Линия 1 (главная). Деньги без рубля — теперь на сервере

Рядом с счетами покупателям, где сумма выглядит как `31 500,00 ₽`, экран
расходов печатает `25 000,00` — то же самое поле, тот же продукт, разная
подпись.

Карта v26 чинила этот же изъян на витрине: четыре экрана считали суммы
своим маленьким форматтером. Тогда сторож закрыл витрину. Но корень
оказался и на сервере, и он общий:

```ts
// Transformer.ts — общий помощник всех трансформеров
protected formatNumber(number, props?) {
  return formatNumber(number, { money: false, ...props });
}
```

`money: false` означает «печатать без знака валюты». Общая утилита
продукта по умолчанию печатает **со** знаком — а этот помощник его
глушит. Дальше каждый трансформер обязан вспомнить и написать
`money: true` руками.

Замер по всему серверу: **вызовов, где валюту передали, а знак погасили —
91** (плюс 6 в отчётах, где голое число уместно и стоит осознанно); тех,
кто вспомнил про `money: true`, — **16**.

Причём отчёты не пострадают: они форматируют суммы **без** валюты
(`FinancialSheet.getAmountMeta` валюту в форматирование не передаёт), а
знак ставят отдельно на итогах. Так что правка попадает ровно в
документы и списки, где сумма — это сумма.

Правило: раз валюту передали — это деньги, знак печатается. Кому нужно
голое число, тот пишет `money: false` явно.

### Линия 2. Описание расхода недостижимо с телефона

В таблице расходов есть столбец «ОПИСАНИЕ». В нём стоит не текст, а
маленький значок, и текст показывается **подсказкой при наведении**.

На телефоне наведения нет. Столбец с заголовком «Описание» на телефоне
не показывает описания вовсе — притом что оно записано (проверено в базе:
«Аренда офиса за месяц» лежит на месте). Продукт мобильный по приоритету
основателя, значит подпись должна читаться пальцем, а не мышью.

## 2. Что проверилось и оказалось здоровым

- Валюта у расходов проставлена (`RUB`) — дело было не в данных;
- отчёты о движении денег и прибылях считают верно, знак валюты на
  итогах стоит;
- демо после карты v29 живёт: оплаты, расходы, ненулевой ДДС.

## 3. Решения владельца — приняты самостоятельно (поручение 27.08)

**Решение 39 — переводить ли план счетов уже созданным организациям.
ДА, но только нетронутые счета.** Новые организации получают русский план
счетов (сид переводит названия по языку организации). Организации,
созданные раньше, живут с английскими «Bank Account», «Petty Cash»,
«Tax Payable». Переименовываем **только** те счета, которые человек не
трогал: у счёта есть слаг, и его текущее название совпадает с английским
эталоном из `i18n/en/account_seed.json`. Переименованный человеком счёт
не трогаем никогда. Делается отдельной командой, которую владелец
запускает осознанно, — а не молча при выкатке.

**Решение 42 — новые списки клиентов и поставщиков.
Оставляем выключенными до полной замены.** Разведка карты v24 показала:
новый список беднее нынешнего — нет видов таблиц, фильтров, переключателя
«Неактивный», импорта, экспорта, печати и кнопки обновления. Включать
такое по умолчанию — отнять у людей рабочие инструменты. Планка приёмки:
включаем, когда в новом списке появятся все семь перечисленных
возможностей. До тех пор флаг остаётся выключенным, код живёт как задел.

**Решение 43 — организация-призрак `2kjb34bma6mt9c2c15`.
Убрать запись со стенда.** За записью нет базы данных (наследие поломки
25.08), значит терять нечего. После карты v28 призрак больше не рвёт
общий прогон миграций, так что это уборка, а не починка. Запись
сохраняется в файл перед удалением — на случай, если владелец захочет
вернуть.

## 4. Фаза «Деньги без рубля, часть вторая» — срезы

1. **Д1 — деньги печатаются со знаком валюты.** Общий помощник
   трансформеров печатает знак, когда ему передали валюту; кому нужно
   голое число — пишет `money: false` явно. Сторож: денежное поле
   трансформера не глушит валюту молча. Живьём: на экране расходов
   `25 000,00 ₽`.
2. **Д2 — описание расхода видно без наведения.** Столбец печатает текст
   (с усечением длинного и подсказкой на полный), а не значок.
3. **Д3 — русские названия счетов старым организациям (решение 39).**
   Команда `tenants:translate-accounts`: для каждой организации берёт её
   язык и переименовывает только нетронутые счета по слагу. Прогон на
   стенде — живая проба.
4. **Д4 — уборка призрака (решение 43).** Операция на стенде: сохранить
   строку метаданных в файл, удалить, проверить полный прогон миграций.

Порядок: Д1 → Д2 → Д3 → Д4.
Каждый срез: красный тест → правка → полные прогоны → живая проба на
собранной витрине → PR с числами.
