# Bigfin — Дорожная карта v69 «Работает или нет» — 2026-09-08

Карта v68 влита (#399). Задел: 71 пара «тег — свойство», по каждой нужно
доказать по исходникам библиотеки, читается свойство или нет.

Поручение владельца: решения принимать самому.

---

## 1. Вопрос, на который нельзя ответить по названию

Все эти замечания читаются одинаково: «компонент не объявил свойство». Но
дальше есть ровно два ответа, и они противоположны:

- свойство **не читается** — значит, оно ничего не делает, и его надо убрать
  у вызывающих;
- свойство **читается**, просто не объявлено — значит, объявление чужого
  пакета уже правды, и дописать надо его.

Ответ виден только в исходниках самой библиотеки. По названию свойства —
никогда: `fastField` у одного компонента работает, у соседнего нет.

---

## 2. Что нашлось: всё решает `Field`

Пакет `@blueprintjs-formik/core` собирает свои поля одинаково:

```js
function RadioGroup(props) {
  return React.createElement(Field, __assign({}, props, { component: FieldToRadioGroup }));
}
```

А `Field` объявлен как `FieldBaseProps` — там и живут `fastField` и
`shouldUpdateDeps`. Проверено по каждому: `RadioGroup`, `TextArea`,
`InputGroup`, `Checkbox`, `Switch`, `EditableText`, `HTMLSelect`,
`NumericInput` — **все через `Field`**.

И только один компонент пакета собран иначе:

```js
function FormGroup(_a) {
  var children = _a.children, props = __rest(_a, ["children"]);
  var _b = formik.useField(props.name), …
}
```

**Группа полей — единственная не через `Field`.** Отсюда весь разброс: то,
что у поля работает, у группы не работает никогда.

Выборы (`FMultiSelect`, `FSuggest`) живут в другом пакете —
`@blueprintjs-formik/select`, — и слова `fastField` там нет вовсе.

поля. Проверено пробным файлом в обе стороны: без дополнения проверяемый файл

В самом файле дополнения записано и то, чего там намеренно нет: `fastField` у
группы полей и у выборов — с объяснением, почему.

## 5. Честно

**Волна мала — семь файлов.** Не потому, что правка слабая: 72 свойства
разбросаны по 34 файлам, и почти в каждом остались другие замечания. Из
слепой зоны вышли те семь, где это было последним.

**Ценность карты не в числе файлов, а в разборе.** Одиннадцать пар «тег —
свойство» теперь имеют проверенный ответ, записанный в стороже: не «кажется,
лишнее», а «в исходнике библиотеки этого слова нет» либо «собрано через
`Field`, значит читается».
